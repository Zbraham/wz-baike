# ⚡ 王者百科 · 王者荣耀英雄攻略教学网站

纯前端、零依赖、**完全离线可运行**的王者荣耀英雄百科教学网站。深色电竞风 UI，红蓝点缀，自适应手机 / 电脑，一键打包部署。

> 技术栈：`HTML5 + 手写 Tailwind 风格 CSS + 原生 JavaScript + 本地 ECharts`
> 数据：本地 `json/` 数据文件（无后端、无联网接口）

### 为什么数据用 `.js` 而不是 `.json`？
浏览器在 `file://`（双击打开）协议下**禁止 fetch() 读取本地 .json 文件**（CORS 限制）。把数据写成 `json/*.js` 并通过 `<script>` 注入，可保证「双击 index.html 直接运行」完全离线可用。若你改为部署在 HTTP 服务器上，也无需改动任何代码。

## 🚀 二、运行教程

### 方式一：直接打开（零依赖，推荐）
双击 `index.html`，用浏览器（Chrome / Edge 均可）打开即可完整体验全部功能。**无需安装任何东西、无需联网。**

### 方式二：本地服务器（可选，体验完全一致）
```bash
cd 王者百科
python -m http.server 8080      # 或 npx serve，或任意静态服务器
# 浏览器访问 http://localhost:8080
```

### 部署上线
整个 `王者百科/` 目录就是静态站点根目录，直接整包上传到任意静态托管（Nginx、GitHub Pages、Vercel、OSS 等）即可。

## 🤖 四、接入 DeepSeek（AI 增强）

内置 AI 问答默认使用「本地知识引擎」离线回答常见问题。如需接入真实大模型：

1. 打开 `js/ai-chat.js`，找到顶部配置：

```js
const DEEPSEEK = {
  enabled: true,                                    // ← 改为 true
  apiKey: 'sk-你的Key',                              // ← 填入你的 DeepSeek API Key
  endpoint: 'https://api.deepseek.com/chat/completions',
  model: 'deepseek-chat'
};
```

2. 刷新页面即自动切换为 DeepSeek 对话。

> ⚠️ 安全提示：前端直填 Key 仅适合本地/演示使用。正式上线建议通过后端代理转发（例如 Nginx + 服务端脚本），避免 Key 泄露。

## 🛠 五、后续迭代建议

1. **扩充详情数据**：已建立生成流水线（`tools/`）。新增英雄流程：按 `tools/GENERATION_GUIDE.md` 规范撰写 → 写入 `json/staging/<id>.js` → `node tools/merge-details.js` 合并 → `node tools/audit-details.js` 巡检查重。已支持全站英雄一键补全与查重。
2. **版本自动更新**：接入官方「英雄时刻/营地」数据接口后，将 `json/season.js` 的梯度与胜率改为动态生成。
3. **出装/铭文迭代**：当前为静态方案，可增加「按敌方阵容推荐出装」规则引擎（克制查询已具备雏形）。
4. **图片资源**：当前头像/图标为 SVG 自动生成，可替换为官方原画，仅需改 `js/utils.js` 中 `heroAvatar` / `itemIcon`。
5. **数据校验脚本**：`node` 下可对 json 做引用完整性检查（本项目交付时已实现并全部通过）。
6. **多语言 / 深色浅色切换**：设计变量集中在 `css/style.css` 顶部 `:root`，可一键扩展主题。
7. **收藏/浏览历史**：利用 `localStorage` 实现我的英雄、最近浏览等功能。
